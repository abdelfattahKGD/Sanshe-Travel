# Word Forge 📚

تطبيق أندرويد أوفلاين لتعلّم الإنجليزي: كلمات وجمل بالترجمة، بطاقات مراجعة بالتكرار المتباعد (SRS)، تدريب اختيار من متعدد، إحصائيات، ومهام يومية.
مكتوب بـ Kotlin + Jetpack Compose، والـ APK بيتبني على GitHub Actions.

## 1) البناء على GitHub (من غير ما تثبّت أي حاجة)

1. اعمل Repository جديد على GitHub وارفع محتوى هذا المجلد كله (بما فيه المجلد المخفي `.github`).
2. أول ما ترفع، شغّال تلقائيًا: **Actions → Build APK**. ولو مشتغلش اضغط **Run workflow**.
3. لما يخلص، افتح الـ run ونزّل **WordForge-debug-apk** من قسم Artifacts، فُك الضغط وثبّت الـ `app-debug.apk` على الموبايل.
4. لو البيلد فشل: افتح الـ run، انسخ آخر الـ log (من أول `error:` أو `FAILED`) وابعته لي.

## 2) إضافة محتوى (موضوع جديد)

المحتوى بيتكتب كنص بسيط في `data_src/topicNN.txt` (شوف `topic01.txt` كنموذج):

```
@group g1|اسم المجموعة بالعربي|Group name
@words
g1|A1|hello|interj|مرحبًا|Hello, everyone, welcome back!
@sentences
g1|A1|Hi! How are you doing?|أهلًا! كيف حالك؟
```

1. اكتب الملف، وحط اسمه في `src` للموضوع جوه `data_src/topics.json`.
2. شغّل `python3 tools/build_data.py` — بيحوّله لـ JSON جوه `app/src/main/assets/data/` وبيتحقق من: التكرار، عدد كلمات المثال (3–7) والجملة (5–12)، المستويات، والمجموعات.
3. ارفع التغيير على GitHub. **مفيش أي كود لازم يتغيّر**، والموضوع بيظهر لوحده في التطبيق.

## 3) إضافة ميزة جديدة (شاشة)

كل شاشة هي كلاس بيطبّق `Screen` (في `ui/Core.kt`). لإضافة ميزة:
1. اكتب الكلاس/الـ object الجديد (زي `ui/OtherScreens.kt`).
2. زوّد سطر واحد في `Registry.drawer` داخل `ui/Core.kt`.

والباقي (الداتا، التقدّم، الإحصائيات) متاح لها من `env.repo`.

## الحالة الحالية (المرحلة 1)

- ✅ موضوع 1 كامل: 100 كلمة + 100 جملة في 8 مجموعات (باقي المواضيع قيد الكتابة)
- ✅ الشاشة الرئيسية (تقدّم، مهام اليوم، ستريك) + قائمة جانبية
- ✅ تصفح الكلمات والجمل حسب الموضوع/المجموعة، نطق (TTS)، نجمة للمفضلة
- ✅ بطاقات مراجعة SRS + تدريب اختيار من متعدد + بحث + إحصائيات + إعدادات الأهداف
- 🔜 الجرامر والامتحانات (المرحلة 3) — موجودين في القائمة كـ "قريبًا"
